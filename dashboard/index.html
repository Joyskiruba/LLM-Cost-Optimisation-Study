The first row is the baseline. Faded rows are hidden from the charts by the filters.

Costs are modeled from OpenAI's published per-token pricing and a simulated 1,000-request traffic sample, not a live API bill. Accuracy = answer correctness vs 38 gold answers. Source: LLM Cost Optimisation Study.

Notes and assumptions

Cache hit rates left blank in the study results are entered as 0%. Config 2b is the caching-without-routing ablation.

Token counts are estimated at about 1.3 tokens per word, with gpt-4o and gpt-4o-mini prices checked in September 2026. gpt-4o and gpt-4o-mini are stood in for by strong and weak generators (no live model calls).

Traffic is 1,000 simulated requests from a 41-question set with a Zipf-shaped repeat distribution, a stated assumption because real production logs were not available.

Value score = accuracy points ÷ cost per 1,000 requests. Accuracy change is in percentage points vs the baseline. Cost charts use a log scale because costs span about 400x.
